# Frontend Technology Stack

| Component | Technology | Role |
| --- | --- | --- |
| Language | TypeScript 5.8 | Application development and static typing |
| UI framework | React 19 | Build the workstation interface |
| Framework and routing | TanStack Start, TanStack Router | Server-side rendering and file-based routing in `src/routes/` |
| Server state | TanStack Query 5 | Manage server queries and cached data |
| Styling | Tailwind CSS 4 | Build interfaces with utility classes |
| UI primitives | Radix UI | Accessible primitives such as dialogs, labels, and switches |
| Icons | Lucide React | Interface icons |
| Build and development server | Vite 8 | Run the development server and build the application |
| Code quality | ESLint 9, TypeScript ESLint | Check source code |
| Media server | Caddy or Node.js server | Serve keyframes, videos, and map files; Caddy supports HTTP/2 |
